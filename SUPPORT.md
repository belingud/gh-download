# Support

Use GitHub Issues for questions, bug reports, and feature requests:

- Bug report: include the command, operating system, installation method, version, authentication mode, proxy mode, expected result, actual result, and redacted logs.
- Feature request: describe the workflow you want to improve and the behavior you expect from the CLI.
- Security-sensitive report: do not open a public issue; see `SECURITY.md`.

Before opening an issue, check:

- `README.md`
- `README.zh.md`
- Existing open and closed issues

Never include GitHub tokens, private repository URLs with embedded credentials, or unredacted debug output in public comments.
